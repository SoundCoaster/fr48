# Flightradar48

A Flightradar24-style live flight tracker for the [VATSIM](https://vatsim.net) network, built with Next.js and MapLibre and deployed on Cloudflare Workers.

## Features

- Live map of every VATSIM pilot, animated between updates (dead reckoning), with aircraft silhouettes by type
- Flight panel: route and progress, scheduled/actual/estimated times, aircraft photo (Planespotters.net, from the `REG/` filed in the flight plan), live data, pilot, full flight plan
- Flown trail colored by altitude, kept server-side so it is visible even when you open a flight mid-way, plus a dashed great-circle path to destination
- Search across flights, airports and airlines; filters by airline, aircraft type, airport, callsign, altitude, ground/air
- Airport panel and full airport pages: arrivals and departures boards, on-ground traffic, decoded METAR, ATC online with ATIS
- Map styles (light, voyager, dark, satellite), unit and time zone settings, callsign labels, widgets

## Architecture

```
VATSIM data feed (15 s) ──▶ TrafficTracker Durable Object ──▶ /api/* route handlers ──▶ React client (MapLibre)
                              • polls on an alarm
                              • keeps trails and take-off/landing times in memory
                              • gzipped snapshot every 5 min
```

- `worker/` — custom Worker entry and the `TrafficTracker` Durable Object
- `src/lib/traffic-store.ts` — ingests feed snapshots, builds trails, detects take-off and landing
- `src/lib/derive.ts` — flight details, airport boards, search
- `src/components/map/LiveMap.tsx` — map rendering and animation
- `src/data/` — reference data generated by `npm run data` (VATSpy, OurAirports, OpenFlights); `aircraft.ts` maps ICAO types to names and silhouettes

During `next dev` the Durable Object is replaced by an in-process singleton, so no Cloudflare tooling is needed to work on the UI.

## Development

```bash
npm install
npm run dev        # http://localhost:3000
npm run preview    # production build in the local Workers runtime (wrangler)
npm run deploy     # build and deploy to Cloudflare
npm run data       # refresh airport/airline reference data
```

## Custom assets

- Airline logos: drop `public/airlines/{ICAO}.png` (for example `AFR.png`). Falls back to a public IATA logo CDN, then to a text badge.
- Logo: `src/components/Logo.tsx` is a placeholder mark.
